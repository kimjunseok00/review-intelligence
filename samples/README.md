저장소에는 올리지 않는다(용량, 이용 조건). 각자 받아서 `samples/raw/`에 둔다(.gitignore 처리됨).
받은 출처, 날짜, 이용 조건은 `docs/EXPERIMENTS.md`에 기록한다.

- 네이버 쇼핑 리뷰 약 20만 건 (평점 + 리뷰 텍스트로 알려짐, 작성일 포함 여부 확인 필요)
- AI Hub '속성 기반 감성분석 데이터' (속성·감정 라벨 포함, 가입과 이용 신청 필요)
