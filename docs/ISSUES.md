## #2 리뷰 묶음 분류 엔진
- 담당: 팀원 A / 1주차 / engine
- 수정: `engine/classify.py`, `prompts/classify.txt`, `tests/test_engine_*.py`

**할 일**
- `classify_reviews` 구현. `config.BATCH_SIZE`개씩 묶어 `call_llm_json(prompt, LLMBatch)`.
- 프롬프트는 `labeling/LABEL_GUIDE.md`를 옮겨 작성.
- 돌아온 idx 검증, 빠진 리뷰만 재요청, 두 번째도 실패하면 `LLMError`.

**완료 조건**
- 리뷰 120건을 넣으면 120개 라벨이 같은 순서로 나온다. 호출 횟수(`core.llm.usage["calls"]`)가 3회 안팎이다.
- LLM이 idx 하나를 빼먹는 경우를 가짜 응답으로 만들어, 재요청이 동작하는 테스트가 있다.
- 공개 리뷰 50건 결과를 PR에 붙인다(사람이 훑어보고 이상한 것 표시).
